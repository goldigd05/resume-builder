  # 📝 Smart Resume Builder
A professional, responsive, and theme-customizable Resume Builder web app built using HTML, CSS, and JavaScript. Easily create, preview, and download your resume as a PDF — all in the browser!
## 🔥 Features
- 🚀 Create and preview resume instantly
- 🎨 Multiple themes: Mesho, Indigo, Teal
- 🌗 Light/Dark mode toggle
- 📄 Download resume as PDF
- 📷 Upload profile photo
- 🧑 Add sections: Education, Experience, Skills, Projects, Certificates
- 🔗 Add social links and contact details
- 💾 Data stored temporarily using `localStorage`
## 🛠️ Tech Stack
- **Frontend: HTML5, CSS3, JavaScript (Vanilla)
- PDF Generation: `html2pdf.js`
- Icons: Font Awesome
## ✅ How to Use
1. Clone this repo or download the ZIP.
2. Open `index.html` in your browser.
3. Fill in your resume details.
4. Click "Generate Resume".
5. Preview it on the next page and click "Download PDF".

## 📌 Future Improvements
